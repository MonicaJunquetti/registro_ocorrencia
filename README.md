# 📱 Registro de Ocorrência (Projeto Educativo)

> 🎓 **Trabalho Acadêmico:** Projeto desenvolvido para a disciplina de *Aplicações Mobile* (Análise e Desenvolvimento de Sistemas)[cite: 1].

Aplicativo simples em **Flutter** para registrar ocorrências capturando uma **foto** e a **localização exata (GPS)** do dispositivo[cite: 2].

---

## ✨ Funcionalidades

- 📷 **Tirar Foto:** Abre a câmera e exibe a imagem na tela[cite: 2, 7].
- 📍 **Obter Localização:** Captura latitude, longitude e precisão do GPS[cite: 2].
- 🔒 **Permissões:** Pede autorização do usuário apenas no momento de usar a câmera ou localização[cite: 5].

---

## 🛠️ Tecnologias Utilizadas

- **Flutter** e **Dart**
- **[image_picker](https://pub.dev/packages/image_picker)** (Câmera)[cite: 2, 4]
- **[geolocator](https://pub.dev/packages/geolocator)** (GPS)[cite: 2, 4]
