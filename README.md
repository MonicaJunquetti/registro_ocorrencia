# 📱 Registro de Ocorrência (Projeto Educativo)

> 🎓 **Trabalho Acadêmico:** Projeto desenvolvido para a disciplina de *Aplicações Mobile* (Análise e Desenvolvimento de Sistemas).

Aplicativo simples em **Flutter** para registrar ocorrências capturando uma **foto** e a **localização exata (GPS)** do dispositivo.

---

## ✨ Funcionalidades

- 📷 **Tirar Foto:** Abre a câmera e exibe a imagem na tela.
- 📍 **Obter Localização:** Captura latitude, longitude e precisão do GPS.
- 🔒 **Permissões:** Pede autorização do usuário apenas no momento de usar a câmera ou localização.

---

## 🛠️ Tecnologias Utilizadas

- **Flutter** e **Dart**
- **[image_picker](https://pub.dev/packages/image_picker)** (Câmera)
- **[geolocator](https://pub.dev/packages/geolocator)** (GPS)
